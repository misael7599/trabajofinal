# Recetas de Comida

Pagina web sobre recetas caseras faciles y rapidas. Incluye secciones informativas, tabla de ingredientes y formulario de contacto.

## Secciones

- **Inicio:** bienvenida, lista de caracteristicas, imagen y enlace externo con aside de consejo
- **Recetas:** fideos con salsa de tomate y ensalada fresca, cada una con pasos y video de YouTube
- **Ingredientes:** tabla con colspan y rowspan mostrando los ingredientes por receta
- **Contacto:** formulario con validacion de campos para enviar tu propia receta

## Tecnologias usadas

- HTML5
- CSS3
  - Variables CSS (custom properties)
  - Flexbox
  - Grid
  - Responsive design con media queries
  - Transiciones y animaciones
  - Pseudoclases y selectores avanzados
- Google Fonts (Oswald)

## Caracteristicas

- Header sticky con navegacion
- Scroll suave entre secciones
- Diseño responsive para mobile y desktop
- Hover effects en links, botones y cards
- Formulario con estilos en focus
